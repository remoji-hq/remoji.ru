# Общее

В идеале любая работа по ремонту помещения начинается с проекта. Этап проектирования позволяет максимально продумать и просчитать все детали будущего ремонта, что позволяет свести к минимуму неприятные неожиданности при выполнении работ на объекте.

В англоязычной литературе этот этап называется Building Information Modeling (BIM).

## Программное обеспечение

Существует множество программ для проектирования зданий, планировки помещений, а также детализации инженерных систем. Большая часть из них относится в платному ПО, но встречаются также и бесплатные аналоги с открытым исходным кодом.

- [Graphisoft Archicad](https://www.graphisoft.com/plans-and-products/archicad) &mdash; один из самых известных и распространённых программных пакетов для архитекторов, основанный на технологии информационного моделирования. Предназначен для проектирования архитектурно-строительных сооружений и решений, а также элементов ландшафта, мебели и т. п.

- [Autodesk Revit](https://www.autodesk.com/products/revit/overview) &mdash; программный комплекс для автоматизированного проектирования, реализующий принцип информационного моделирования зданий. Он предоставляет возможности трёхмерного моделирования частей здания и плоского черчения элементов оформления, создания пользовательских объектов, организации совместной работы над проектом.

- [SketchUp](https://sketchup.trimble.com/) &mdash; программа для 3D-дизайна и архитектурного проектирования. В основном используется для моделирования жилых домов, мебели, интерьера.

- [FreeCAD](https://www.freecad.org/) &mdash; FreeCAD — параметрическая САПР общего назначения[9] с открытым исходным кодом. Содержит в себе модуль [Архитектура](https://wiki.freecad.org/Arch_Workbench), который позволяет работать с информационной моделью здания, совместимой с форматом [Industry Foundation Classes](https://ru.wikipedia.org/wiki/Industry_Foundation_Classes).
